# a) Install Ghidra.
Menin Googlen kautta Ghidran sivulle (www.ghidra.net) ja avasin Github-linkin josta Ghidran saa ladattua.

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4ghidra.png" width="600">

unzippasin tiedoston samaan kansioon "unzip ghidra_12.1.3_PUBLIC_20260817.zip"

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4ghidra2.png" width="600">

Vaihdoin Ghidran hakemistoon ja kokeilin ajaa ./ghidraRun

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4ghidra3.png" width="600">

Tuli tälläinen error Javaan liittyen. 

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4ghidra4.png" width="600">

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4ghidra5.png" width="600">

Tutkin Ghidran nettisivuja ja löysin että ohjeissa suositellaan Java Development Kit 21. Asensin JDK 21 terminaalissa komennolla "sudo apt install openjdk-21-jdk" jonka jälkeen ./ghidraRun komento toimi ja Ghidra käynnistyi.
