# c) If backwards

Importtasin passtr-tiedoston Ghidraan samanlailla kun tein packd-tiedoston kanssa.

Tarkoituksena on tehdä salasanan hyväksynnästä käänteinen niin että kaikki muut paitsi "sala-hakkeri-321" kelpaavat.

Helpoin tapa tehdä tämä mielestäni on muuttaa kohtaa "iVarl == 0" jossa 0 tarkoittaa että syötetty merkkijono täsmää oikeaan salasanaan. Yritin ensin muuttaa merkkiä yhtäsuuresta erisuureksi suoraan decompilerissä mutta se ei toiminut.

Päätin sitten yrittää tehdä muutoksia listing-puolella, maalasin tuon haluamani kohdan että Ghidra näyttää sen tiedot listing-puolella.

<img src="https://raw.githubusercontent.com/Ralchuu/sovellustenhakkerointi/main/h4-1.png" width="800">

Alunperin 74 11 JZ tilalla oli 75 11 JNZ. Kysyin tekoälyltä mitä 85 c0 TEST EAX, EAX ja 75 11 JNZ tarkoittaa.

TEST EAX tarkastaa onko arvo 0, ja JNZ (Jump if not zero) suorittaa hypyn jos arvo ei ole 0.

Ilmeisesti TEST kohdassa katotaan täsmääkö salasana syötteeseen, ja jos kyllä niin JNZ ei aktivoidu koska arvo on 0.

Haluamme siis muuttaa JNZ niin että se on "Jump if zero" jotta kaikki toimii käänteisesti.

Kysyin tekoälyltä miten tämä tehdään ja vastaus oli niinkin yksinkertainen että JNZ muutetaan JZ.
